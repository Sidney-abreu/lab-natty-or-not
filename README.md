# Natural ou Fake Natty? - Gerente de Projetos em Home Office

## 📒 Descrição
Criei uma imagem hiper-realista com IA Generativa de um Gerente de Projetos trabalhando em home office. Parece uma foto real tirada com celular, mas nenhuma pessoa real posou para ela. O objetivo é mostrar como é difícil distinguir conteúdo natural de conteúdo gerado por IA.

## 🤖 Tecnologias Utilizadas
- IA Generativa de imagem - Meta AI
- Prompt em português / inglês para gerar foto realista

## 🧐 Processo de Criação
Pedi para a IA criar uma foto realista, estilo candid, de um homem em home office, com laptop, caderno, café, luz natural de janela. Pedi detalhes reais: pele com textura, cabelo, planta, xícara com vapor. Não usei nenhuma foto real como base.

## 🚀 Resultados
A imagem ficou muito realista à primeira vista. Ao olhar com atenção, aparecem erros típicos de IA: textos na tela do notebook distorcidos, palavras inventadas no caderno e na interface. É o sinal de Fake Natty.

## 💭 Reflexão
Criar algo 'natty' com IA é fácil hoje. O difícil é criar algo perfeito. Por isso, no trabalho, precisamos sempre conferir: texto, mãos, letras e detalhes. IA ajuda muito, mas o olhar humano ainda é necessário para validar.
